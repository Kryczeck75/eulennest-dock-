🦉 Eulennest Dock
Access Token braucht die Scopes: chat:read chat:edit moderator:manage:banned_users moderator:manage:chat_messages channel:manage:broadcast user:read:email user:manage:blocked_users channel:read:redemptions channel:manage:redemptions. Für die Follower-Anzeige zusätzlich optional: moderator:read:followers (ohne diesen Scope funktioniert alles andere weiterhin, nur das Follower-Badge bleibt dann aus). Für die Sub-Tier-Anzeige (T1/T2/T3) zusätzlich optional: channel:read:subscriptions (ohne diesen Scope werden Tiers erst erkannt, sobald jemand während der laufenden Sitzung abonniert/resubbed). Für den Whisper-Ping zusätzlich optional: whispers:read. Für die Ziele-/Hype-Train-Anzeige zusätzlich optional: channel:read:goals und channel:read:hype_train (ohne diese Scopes bleiben die jeweiligen Funktionen einfach inaktiv). Refresh Token gibt es nur über den Authorization-Code-Flow (nicht Implicit Flow) — z. B. über twitchtokengenerator.com (Custom Scope Token, "Bot Chat Token" Modus) mit deiner Client-ID + Client Secret. Das Dock erneuert den Access Token damit automatisch, du musst danach nichts mehr manuell nachtragen. Alles bleibt nur lokal in diesem Browser (localStorage) gespeichert.
